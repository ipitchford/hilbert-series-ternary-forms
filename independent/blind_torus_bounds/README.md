# b_r(d) for S^d(C^3) under the diagonal torus of SL3 (written for d = 5, 6, 7; also run for d = 8, 9)

*Producer note (not part of the blind agent's text): the program accepts any d as an argument. The same unmodified code produced `results_d8.json` and `results_d9.json`, and replay mode `fresh` reruns it for d = 5..9 in a temporary copy.*

Files: `poles.py` (main exact computation), `sanity.py` (hand examples), `crosscheck.py`
(independent brute force over torsion t), `results_d{5,6,7}.json` (r -> b_r, only b_r > 0 listed).
Run: `python poles.py 5 6 7` (~45 s), `python sanity.py`, `python crosscheck.py 5 6 7` (~15 s).

## Reduction (why this covers all t, including non-torsion t, and all r)

Let phi: Z^2 -> C^*, w -> chi_w(t). Since (t1,t2) is arbitrary in (C^*)^2, phi is an arbitrary homomorphism.
Put Phi: Z^3 -> C^*, Phi(w,k) = phi(w) zeta^{-k}; as (t,zeta) vary, Phi ranges over ALL homomorphisms Z^3 -> C^*,
and zeta^{-1} = Phi(e3).

For S ⊆ W let M(S) = <(w,1) : w in S> ⊆ Z^3 and o(S) = order of e3 in Z^3/M(S) (0 = infinite).
S lies inside a level set S(t,zeta) with zeta of exact order r  <=>  some hom Phi kills M(S) and Phi(e3) has order r.

* If kappa(S) > 0 there is an integer relation sum c_w w = 0, c >= 0, N = sum c_w > 0, so N e3 in M(S): o(S) finite.
* Achievable orders of Phi(e3) for Phi in Hom(Z^3/M, C^*) are exactly the divisors of o(S): the image of e3 is a
  torsion element of order o(S); Hom(-, C^*) is exact because C^* is divisible, so the characters restrict
  surjectively onto Hom(<e3>, C^*) = Z/o(S).

kappa is monotone under inclusion, so
    b_r(d) = max{ kappa(S) : S ⊆ W, kappa(S) > 0, r | o(S) }   (0 if the set is empty).
The maximum is attained at an actual level set. Every level set S = W ∩ (w0 + ker phi) satisfies
S = W ∩ (w0 + L(S)), where L(S) is the lattice generated by the differences of S. (⊇ is clear, and ⊆ holds
because L(S) ⊆ ker phi.) So it is enough to range over the sets W ∩ (w0 + L), with w0 in W and L one of:
* rank 0;
* rank 1: L = Z v with v in the box [-2d,2d]^2 (every difference, and hence the generator of L(S), lies there);
* rank 2: all sublattices of Z^2 of index <= 8 d^2. These are enumerated uniquely by HNF bases (p,q),(0,s),
  0 <= q < s, index p*s. The bound holds because the index of L(S) is at most |det| of any two independent
  differences, and that is <= 2(2d)^2.
This finite family contains every level set, and it also contains some non-realisable sets. Those extras do no
harm, because the criterion r | o(S) is valid for any subset. The enumeration therefore covers every t in T,
torsion or not, and every r >= 1. b_r is nonzero only for divisors of the finitely many o(S), so the list is finite.

## Exact subroutines
* kappa(S): P = {w in S : -w in cone(S)} is the set of coordinates that can be positive in a relation. The exact
  2-D test uses Caratheodory (1 or 2 generators, Fraction arithmetic). Adding the relations for all w in P gives a
  point of the cone that is positive on all of P, so dim = |P| - rank(P).
* o(S): integer row echelon (Euclid) of the rows (w1, w2, 1). M(S) ∩ (0,0,Z) is generated by the echelon row with
  its pivot in column 3.

## Checks
* sanity.py hand examples: {(1,0),(-1,0)} gives kappa 1, o 2. {(1,0),(0,1),(-1,-1)} gives kappa 1, o 3. {(2,0),(-1,0)}
  gives kappa 1, o 3. The 4 collinear points ±1, ±2 give kappa 3, o 1. The cross gives kappa 2, and the full W for
  d=3 gives kappa 8 = 10 - 2.
* crosscheck.py enumerates torsion t = (e^{2πia/n}, e^{2πib/n}) for n <= 40 and n in {r, 2r, 3r}. It takes every
  level set with exact kappa and the order of zeta. For d = 5, 6, 7 it never exceeds the table and attains every
  table value, so every entry has an explicit witness. For d=6, r=15 the witness needs t of order 45.
* Structural check: when 3 does not divide d, the centre ω·I multiplies zeta by ω^d. So b_3 = b_1 = |W| - 2, and
  b_{3r} >= b_r for r coprime to 3. Both appear in the tables for d = 5 and 7.
