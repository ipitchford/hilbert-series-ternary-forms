# Unconditional Hilbert series of plane-septic invariants: pole-order bounds

**Claim.** Let I = C[S^7 C^3]^{SL_3}. Then H(I, t) = R(t), where R is the candidate in `results/d7_rational.json`: in lowest terms, deg D = 1386 and deg N = 1350.

Notation used throughout:
- A = I, graded by degree, with Krull dimension δ = 28.
- X = Spec A = V//G, where V = S^7 C^3 and G = SL_3.
- π: V → X is the quotient map.
- T ⊂ G is the diagonal torus.
- W is the set of 36 weights of V, written in the coordinates (a−c, b−c) for the monomial x^a y^b z^c.

## Lemma A (pole order and fixed locus)

**Statement.** Let A be a finitely generated, positively graded C-algebra with A_0 = C, and let ζ be a primitive r-th root of unity. Let I_r be the ideal generated by the homogeneous elements whose degree is not divisible by r. Then the pole order of H_A at t = ζ is at most dim A/I_r.

**Proof.**
1. Let f_1, …, f_m be homogeneous generators of I_r, with degrees e_i, where r ∤ e_i.
2. For a finitely generated graded A-module M and f = f_i, the exact sequence 0 → (0:_M f)(−e) → M(−e) → M → M/fM → 0 gives (1 − t^e) H_M = H_{M/fM} − t^e H_{(0:_M f)}.
3. Since 1 − ζ^e ≠ 0, the pole order of H_M at ζ is at most the maximum of the pole orders of H_{M/fM} and H_{(0:_M f)}.
4. Both modules are annihilated by f. Submodules and quotients of modules annihilated by f_1, …, f_j are still annihilated by them.
5. Starting from M = A and applying this step for f_1, …, f_m in turn, the pole order of H_A at ζ is bounded by the maximum of the pole orders of finitely many finitely generated graded A/I_r-modules.
6. A/I_r is finite over a graded polynomial ring in s = dim A/I_r variables (Noether normalisation). So by Hilbert–Serre each of those Hilbert series has pole order at most s at any root of unity. ∎

## Lemma B (the fixed locus)

**Statement.** V(I_r) = X^ζ, the set of points fixed by the grading action of ζ. Moreover
X^ζ = ⋃_{t ∈ T} π(V_{S(t)}), where S(t) = {w ∈ W : χ_w(t) = ζ} and V_S = ⊕_{w∈S} V_w.

**Proof.**
1. For homogeneous f of degree e, f(ζv) = ζ^e f(v). So π(v) ∈ V(I_r) if and only if every invariant takes the same value at v and at ζv, that is, π(ζv) = π(v).
2. Take v with Gv closed. Then G(ζv) = ζ·Gv is closed and lies in the same fibre as Gv. A fibre contains exactly one closed orbit, so ζv = gv for some g ∈ G.
3. Let g = g_s g_u be the Jordan decomposition. An eigenvector of g with eigenvalue ζ lies in the ζ-generalised eigenspace of g_s, so g_s v = ζv.
4. Conjugate g_s into T: t = h g_s h^{-1}. Then t(hv) = ζ(hv) and π(hv) = π(v).
5. The converse inclusion is immediate from step 1. ∎

(Whether ζ or ζ^{-1} appears depends on conventions. The bound below takes the maximum over all primitive r-th roots, so this does not matter.)

Only finitely many subsets S(t) ⊆ W occur, because |W| = 36. X^ζ is therefore a finite union, and its dimension is the maximum over the pieces.

## Lemma C (dimension of each piece)

**Statement.** dim π(V_S) ≤ dim V_S//T = κ(S), where:
- κ(S) = dim{c ∈ R^S_{≥0} : Σ c_w w = 0} = |S_0| − rank(S_0);
- S_0 = {w ∈ S : −w ∈ cone(S)}.

**Proof.**
1. π restricted to V_S is T-invariant, so it factors through the categorical quotient V_S → V_S//T.
2. C[V_S]^T is the monoid algebra of the nonnegative integer relations among the weights. Its Krull dimension is the dimension of the cone of nonnegative real relations.
3. That cone lies in R^{S_0}. It contains a strictly positive relation there, so it is full-dimensional in the kernel of the map R^{S_0} → R^2, which has dimension |S_0| − rank(S_0). ∎

## Enumeration (exact)

Write S = W ∩ φ^{-1}(ζ) for a homomorphism φ: Z^2 → C^*. There are three cases.

**(i) rank(S − S) = 2.**
- ker φ contains a rank-2 lattice generated by weight differences. Its index is therefore at most the largest |det| of two differences, which is 147 for d = 7.
- Z^2/ker φ is finite cyclic, and ζ = φ(w_0) has order equal to the order of w_0 in that quotient.
- The script enumerates every kernel of a map (x, y) ↦ cx + ey mod N with N ≤ 147. Every kernel has a representative with c | N:
  - start from a primitive map (a, b) mod N;
  - put c = gcd(a, N), with c = N when a ≡ 0;
  - choose a unit k modulo N with ka ≡ c (mod N). This is possible because units mod N surject onto units mod N/c;
  - (ka, kb) has the same kernel as (a, b).

**(ii) rank(S − S) = 1.**
- If the line containing S misses 0, then some linear functional is positive on S, so κ = 0.
- If the line passes through 0 with direction u (u primitive), write the points of W on that line as k·u for k in a finite set K_u.
  - If z = φ(u) has infinite order, then z^k = ζ has at most one solution k, so |S| ≤ 1.
  - If z has finite order M, then S ⊆ {ku : k ∈ K_u, k ≡ ρ (mod M)}, where ζ = z^ρ, so r = M / gcd(M, ρ).
  - If M > max K_u − min K_u, every class contains at most one k, so |S| ≤ 1.
  - The script therefore enumerates M from 1 to 2·max|k| + 1 and every ρ, for every primitive direction u through a weight.
- κ is monotone under inclusion, so it suffices to evaluate κ on these classes.

**(iii) |S| = 1.** κ = 0, unless S = {0}.

The result is b_r = max κ(S) over all level sets S with ζ of exact order r.

**Exhaustiveness.** Every level set, for every r and every primitive ζ, falls under case (i), (ii) or (iii). In each case it is contained in a set the script enumerates, with the same r. So any r not recorded with a positive value has b_r = 0: every level set for that r has κ = 0, the fixed locus is the vertex, and by Lemma A H has no pole at primitive r-th roots. For d = 7, W contains no zero weight, so singletons give κ = 0. The positive b_r occur exactly at the 48 orders listed in `pole_bounds_d7.json`. The pole order of H at a primitive r-th root of unity is at most p_r = min(28, b_r). The bound 28 comes from Noether normalisation, via Hilbert–Serre.

## Certificate

1. Let B' = ∏ Φ_r^{p_r}. It has degree 1452. By Lemmas A–C, H·B' is a polynomial P'.
2. B'(1/t) = (−1)^{p_1} t^{−1452} B'(t), and p_1 = 28 is even. Together with the functional equation H(1/t) = t^{36}H(t) (paper §3.1), this gives P'(t) = +t^{1416} P'(1/t), with the sign +.
3. A polynomial Q of degree ≤ 1416 with Q(t) = t^{1416}Q(1/t) is determined by its coefficients of degree ≤ 708. So P' is determined by a_0, …, a_708, which are known exactly up to degree 760.
4. `certify_septic_unconditional.py` checks, in exact integer arithmetic, that:
   - D_R divides B';
   - Q := R·B' is a polynomial of degree ≤ 1416;
   - Q(t) = +t^{1416} Q(1/t) coefficient by coefficient;
   - the series of R equals the exact a_n for every n ≤ 708.
5. So P' and Q are reciprocal polynomials of degree ≤ 1416 with the same coefficients up to degree 708. Hence P' = Q and H = R.

## Validation on known cases

For the known ternary quintic and sextic series (Bedratyuk–Xin), the computed b_r bound every true multiplicity. They are positive exactly on the true pole sets. The bounds are frequently sharp, and elsewhere they exceed the true value by exactly 2.

For d = 7, b_r ≥ m_r(R) at every r. The excess is 2 at r ∈ {2, 4, 5, 6, 9, 12, 15, 18} and 0 elsewhere.
